# 원가 차이 관리 — 하이젠알앤엠 기업과제

국립창원대 AIX CREW 2026 · 과제 01 제품별 원가 흐름 분석 · 원가 관리 모델

견적·실적 엑셀을 넣으면 **기종별로 한 대 만드는 원가가 달마다 어떻게 변하는지**, **견적보다 돈이 더(덜) 든 프로젝트가 어디인지(금액 큰 순)**,
그 차이가 **재료를 더 써서인지 · 재료값(고시가)이 올라서인지 · 그 밖의 이유인지** 나눠 보여주고, 담당자가 원인을 메모·확정해 보고서로 내보내는 웹 앱.

- 설치·서버·로그인 없음. `index.html`을 브라우저(Chrome·Edge 최신, Safari 16.4 이상)로 열면 됩니다.
- 파일은 **브라우저 안에서만** 읽고 어디에도 보내지 않습니다. 메모·확정·불러온 데이터는 이 브라우저에 저장됩니다.
- 처음 열면 시연용 **가상 데이터**가 보입니다(화면 위 "가상 데이터" 표시). 데이터 탭에서 우리 파일을 불러오면 "실데이터"로 바뀝니다.

## 매달 쓰는 순서 (월 마감 뒤)
1. **데이터** 탭 → 견적 파일·실적 파일(필수), 지표(고시가) 파일(선택)을 고르고 **불러오기**. 엑셀(xlsx 첫 시트)·CSV 모두 됩니다. 양식이 필요하면 **양식 받기**.
2. **기종** 탭 → "기종 주의"(경고 줄무늬)가 붙은 기종을 먼저 봅니다. **보기 →**로 그 기종 프로젝트만 엽니다.
3. **프로젝트** 탭 → 차이 **금액** 큰 순. "확인 필요" 사유: ① 차이율·금액 하한 넘음 · ② 금액 상한 넘음 · ③ 미분해 몫 큼 · ④ 견적이 오래됨.
4. 프로젝트를 누르면 **상세**: 분해 범위, 한 줄 설명, 견적→실제 폭포형, 당시 견적 기준(버전), 재료별 분해. 원인을 확인해 **원인 메모 → 확정**.
5. **예외** 탭 → 계산에 넣지 못한 행(중복·견적/실적 없음·단위 불일치·빈 값)을 사유와 함께 확인해 원본 파일을 고칩니다.
6. **데이터** 탭 → **결과 내려받기(CSV, 엑셀에서 바로 열림)** · 인쇄/PDF · **메모·확정 백업**(다른 PC·팀원에게 넘길 때).
7. 기준이 우리 회사에 안 맞으면 **설정** 탭에서 확인 필요·기종 주의 기준값, 비교 기준 견적(최종/최초 버전)을 바꿉니다.

## 파일 형식
열 이름은 달라도 됩니다(띄어쓰기·괄호 무시, 비슷한 이름 인식). 한국어 엑셀 CSV(CP949)도 됩니다. 날짜·월은 `2026-03`, `2026.3`, `2026/03`, `202603`, `2026년 3월`, 엑셀 날짜 모두 됩니다.

| 파일 | 필수 열 | 선택 열 |
|---|---|---|
| 견적 | 프로젝트번호, 기종, 견적기준월, 재료코드 + (견적사용량·견적단가 **또는** 견적금액) | 견적버전, 견적작성일, 고객, 생산수량, 판매금액, 재료명, 단위, 단가출처지표 |
| 실적 | 프로젝트번호, 재료코드, 생산완료월 + (실제사용량·실제단가 **또는** 실적금액) | 단위 |
| 지표 | 지표명, 월, 값 | — |

- 같은 프로젝트에 견적 버전이 여러 개면 비교 기준 하나만 씁니다(기본 최종, 설정에서 최초).
- 생산수량이 없으면 기종 개당 원가, 판매금액이 없으면 이익률만 "판단 불가"가 되고 프로젝트 차이 분석은 그대로 됩니다.

## 계산 (정답.md에 손계산 예시)
- 차이 = 사후 − 사전 (+ 더 든 돈, − 덜 든 돈)
- 사용량 효과 = (AQ − SQ) × SP · 단가 효과 = (AP − SP) × AQ
- 고시가 몫 = AQ × (생산월 지표 − 견적월 지표) · 미분해 몫 = 단가 효과 − 고시가 몫 ("원인 불명"이 아니라 "숫자만으로 나누지 않은 몫")
- 원인은 자동으로 정하지 않습니다. 확정은 사람이 메모를 적은 뒤에만 할 수 있습니다.

## 한계
- 기업 담당자 확인 전입니다. 문제 가설(기획서 H1~H4)과 기준값(5%, 30만·200만 원 등)은 Kick-off에서 확정해야 합니다.
- 메모·확정·불러온 데이터는 **이 브라우저에만** 저장됩니다. 공유는 백업 파일과 결과 CSV로 합니다(서버 저장은 다음 단계).
- 노무비·간접비 배부, 가동률 효과, 견적 보정계수, AI 예측은 하지 않습니다. 총액만 있는 항목은 "기타"로 둡니다.
- 고시가 몫은 "구매 단가가 지표를 그대로 따라간다"는 가정의 참고선입니다. 이익률은 견적 판매금액 기준(판매가 불변 가정)입니다.
- 옛 엑셀(.xls)은 읽지 못합니다(xlsx·CSV로 저장).
