# 원가 차이 관리 앱 — 하이젠알앤엠 기업과제

국립창원대 AIX CREW 2026 · 과제 01 제품별 원가 흐름 분석 · 원가 관리 모델

기종별로 한 대 만드는 원가가 달마다 어떻게 변하는지 보여주고, 견적보다 돈이 더(덜) 든 프로젝트를 금액 큰 순서로 세워
그 차이가 **재료를 더 써서인지 · 재료값이 올라서인지 · 그 밖의 이유인지** 나눠 보여주는 반응형 웹 앱.

> 모든 숫자는 시연용 **가상 데이터**입니다. 원인은 자동으로 정하지 않고 담당자가 메모하고 확정합니다.

## 실행
- `index.html`을 브라우저로 열면 됩니다. 서버·설치·로그인 없음.
- 폰에서 열기: GitHub Pages 링크 (아래 "배포" 참고)

| **프로젝트** | 차이 **금액** 큰 순 목록, 확인 필요 표시, 필터(초과/미달·기종·생산월·확인 필요만). 누르면 **상세**: 분해 범위, 한 줄 설명, 견적→실제 폭포형, 당시 견적 기준, 재료별 분해, **원인 메모·확정** | ② 변동 원인 · ③ 사전·사후 비교 |
| **예외** | 계산에 넣지 못한 행(중복·견적 없음·실적 없음·단위 불일치·빈 값)을 버리지 않고 사유와 함께 | 데이터 신뢰 |
| **설정** | 운영 담당자, 확인 필요·기종 주의 기준값, 메모·확정 기록, 자가 검산 결과 | ⑤ 의사결정 활용 |

## 한계 (숨기지 않음)
- **가상 데이터**입니다. 기업 담당자 확인 전이라 문제 가설(H1~H4)은 여전히 가설입니다.
- 메모·확정은 **이 브라우저에만** 저장됩니다(다른 기기·팀원과 공유 안 됨).
- 엑셀 업로드, 기종 오차율, 요인별 브리지, 견적 버전 이력은 2차(실데이터 확보 후) 범위입니다.
- 고시가 몫은 "구매 단가가 지표를 그대로 따라간다"는 가정의 참고선입니다. 미분해 몫은 "원인 불명"이 아니라 "숫자만으로 나누지 않은 몫"입니다.
- 이익률은 견적 판매금액 기준(판매가 불변 가정)입니다.
