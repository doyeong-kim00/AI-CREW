## 조각 7 점검에서 찾은 것 — 검사가 규칙을 시험하지 못하고 있었음
- 고장 복사본("주의 기종 먼저" 정렬 규칙 삭제)이 **202/202 통과** → 검사가 못 잡음
- 원인: 가상 데이터에서 주의 기종 HS-SV가 마침 개당 원가 상승률(+10.0%)도 1위라, 규칙이 있든 없든 순서가 같음
- 조치: 규칙이 있을 때와 없을 때 결과가 갈리는 **정답 M-2**를 손계산으로 추가 — A(+4.0%, 정상) vs B(+1.0%, 이익률 −7.3%p 주의) → 순서 B, A
- 다시 확인: 원래 앱 **203/203 통과**, 고장 복사본 **202/203 실패** ("M-2 순서: 결과 A,B / 정답 B,A")
- 교훈: **데이터가 우연히 맞으면 검사는 규칙을 시험하지 못한다.** 고장 복사본으로 확인해야 드러남.
