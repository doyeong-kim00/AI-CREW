# AI 로그 — 조각 7 (기종별 원가 흐름)

> 날짜: 2026-11-13 · 도구: Claude Code

## 내가 한 요청
"계속 진행, 중간중간 점검·보완"

## AI가 한 일
- 정답 M 작성, `KindModel`(월별 개당 원가 재료비/기타, 기종 주의, 정렬, 추이선 구간)
- 기종 카드 6개(최근 3개월 개당 원가, 변화, 이익률, 추이선, 프로젝트 보기), 선택 기종 큰 차트(0원부터 쌓은 막대 + 견적선 + 월별 표), 운영 담당자 표시
- 설정의 기종 기준값을 따르게 연결
- 점검: 고장 복사본이 통과한 것을 발견 → 정답 M-2 추가

## 내가 판단한 것 / 확인할 것
- 쌓은 막대는 축을 자르지 않음(정직한 표현) — 대신 견적선과 최근 3개월 바탕으로 변화를 보이게
- "검사가 통과했다"가 "규칙이 맞다"는 뜻은 아님 → 고장 복사본 확인을 계속 유지
