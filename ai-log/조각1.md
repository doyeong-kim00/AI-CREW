## AI가 한 일
- plan.md에 승인 표시
- 추가 요청이 spec(R5.2: PC 상단 탭)·CLAUDE.md(외부 라이브러리 없음)와 달라서 **문서를 먼저 고친 뒤** 코드 작성

  - CLAUDE.md: 웹폰트 Pretendard 1개 예외(없어도 작동)
- `index.html` 작성: 디자인 변수, 폰 앱바 + 하단 탭바(알약 표시), PC 사이드바, 화면 4개의 스켈레톤 배치
- 360px·1280px 캡처와 가로 넘침 검사

## 내가 판단한 것 / 고친 것
- 처음 폰 캡처가 잘려 보였음 → AI가 원인을 캡처 도구(최소 창 496px)로 확인하고 iframe 방식으로 다시 검증. 앱 코드는 고치지 않음.
- 스켈레톤 옆 "준비 중 · 조각 N" 표시는 개발 중에만 쓰고 조각이 채워지면 사라진다.

- 내 피드백: "디자인 저게 최선이가 너무 다른 사람들이랑 비슷해"

- 내 선택: C 공장 계기판 (콘크리트 + 안전 노랑/검정, 굵은 숫자, 경고 줄무늬)
- AI가 CLAUDE.md에 디자인 규칙을 먼저 적고 index.html에 반영 → 이후 조각도 이 규칙을 따름
