## R0. 데이터 (가상, 앱 안에 내장)
- R0.1 앱을 열면 파일 없이 바로 가상 데이터로 작동한다. 모든 화면 상단에 "가상 데이터" 표시.
- R0.2 규모: 기간 2025-07 ~ 2026-06(12개월), 기종 6개, **프로젝트 72개 안팎**(기종마다 대부분의 달에 완료 프로젝트 1건 이상, 일부 달은 0건·2건). 고정 시드로 생성해 매번 같은 숫자가 나온다.
- R0.3 구조
  - **견적(행 = 프로젝트 × 재료):** 프로젝트번호, 견적 버전, 견적 작성일, **견적 기준월**, 기종, 고객, 생산수량, 견적 판매금액, 재료코드, 재료명, 단위, 견적 사용량(SQ), 견적 단가(SP), 단가 출처 지표
  - **실적(행 = 프로젝트 × 재료):** 프로젝트번호, 재료코드, 단위, 실제 사용량(AQ), 실제 출고 단가(AP), **생산 완료월**
  - **지표(행 = 지표 × 월):** 지표명(동선·코어·주물), 월, 값(원/kg)
  - 재료: 동선(CU)·코어(CORE)·주물(CAST)은 **분해형**(사용량·단가), 기타 부품(ETC)·가공비(PROC)는 **총액형**(금액만)
- R0.4 일부러 넣는 오류 5건: 중복 행, 견적 없음(실적만), 실적 없음(견적만), 단위 불일치(kg↔g), 빈 단가.
- R0.5 정답.md 예시 A~G의 입력값을 **자가 검산용 고정 데이터**로 따로 넣는다(화면 목록에는 섞지 않고, 설정 화면에 검산 결과만 표시).
- R0.6 **기준 시점은 오늘이 아니라 데이터의 마지막 생산 완료월**(가상 데이터는 2026-06)이다.

## R1. 화면 1 · 기종별 원가 흐름
- R1.1 기종마다 월별 **개당 원가** = 그 달(생산 완료월) 완료 프로젝트 사후원가 합 ÷ 생산수량 합. 견적 개당 원가(사전원가 합 ÷ 수량 합)도 같이.
- R1.2 이익률 = (판매금액 − 원가) ÷ 판매금액. **판매금액은 실제에도 견적 판매금액을 쓴다**(판매가가 바뀌지 않았다는 가정, 화면에 각주로 표시).
- R1.3 **기종 주의** (기준 시점 R0.6, 최근 3개월 = 2026-04~06, 직전 3개월 = 2026-01~03)
  - ① 최근 3개월 개당 원가(수량 가중)가 직전 3개월보다 5% 이상 높음
  - ② 최근 3개월 합계 기준 실제 이익률이 견적 이익률보다 5%p 이상 낮음
  - 어느 기간에 완료 프로젝트가 없으면 그 조건은 **"판단 불가"**로 표시(주의로도 정상으로도 세지 않음).
  - 근거 숫자를 함께 보여준다.
- R1.4 완료 프로젝트가 없는 달은 **0이 아니라 빈칸**(추이선이 끊김)으로 그린다.
- R1.5 폰: 기종 카드 목록(카드 안 작은 추이선). PC: 기종 카드 격자 + 선택한 기종의 큰 추이 차트. 기종을 누르면 그 기종으로 걸러진 화면 2로 간다.
- R1.6 개당 원가 추이는 재료비(분해형 합)와 기타(총액형 합)로 나눠 쌓아 보여준다. *(시간이 모자라면 줄일 수 있는 항목)*

## R2. 화면 2 · 프로젝트 목록
- R2.1 프로젝트별 사전원가 = Σ견적 금액, 사후원가 = Σ실적 금액, 차이 = 사후 − 사전, 차이율 = 차이 ÷ 사전.
- R2.2 **기본 정렬: |차이 금액| 큰 순.** 차이율 순은 토글(역시 절댓값).
- R2.3 필터: 초과만 / 미달만 / 전체, 기종, 생산월, 확인 필요만.
- R2.4 각 항목: 프로젝트번호, 기종, 생산월, 사전, 사후, 차이(부호+색), 차이율, 상태 배지(확인 필요 사유 / 확정됨 / 정상 / 계산 보류).
- R2.5 폰: 카드. PC(≥ 960px): 표 + 오른쪽에 선택한 프로젝트 상세.
- R2.6 상단 요약: 프로젝트 수, 사전 합, 사후 합, 총차이, 확인 필요 수, 확정 수, 예외 수. **합계에는 계산 보류 프로젝트를 넣지 않는다.**

## R3. 화면 3 · 프로젝트 상세
- R3.1 분해형 재료마다 사용량 효과 = (AQ−SQ)×SP, 단가 효과 = (AP−SP)×AQ.
- R3.2 고시가 몫 = AQ × (**생산 완료월** 지표 − **견적 기준월** 지표), 미분해 몫 = 단가 효과 − 고시가 몫. 두 달 중 하나라도 지표가 없으면 고시가 몫 "가정 없음", 단가 효과를 나누지 않고 그대로 표시.
- R3.3 총액형 재료의 총차이는 "기타".
- R3.4 **폭포형 차트**: 사전 → 사용량 효과 → 고시가 몫 → 미분해 몫 → 기타 → 사후. 고시가 몫이 "가정 없음"인 재료가 있으면 그 재료분은 "단가 효과(나누지 않음)" 막대로 따로 둔다. 축을 자르면 "세로축 ○원부터" 표시. 폰에서 좁으면 가로 막대형 폭포로 바꿔도 된다.
- R3.5 **당시 견적 기준** 칸: 견적 버전, 견적 작성일, 견적 기준월, 단가 출처 지표, 생산 완료월, 견적 기준월→생산 완료월 경과 개월.
- R3.6 **분해 범위(%)** 를 맨 위에: Σ|분해형 재료 총차이| ÷ (Σ|분해형 재료 총차이| + Σ|총액형 재료 총차이|). "이 프로젝트 차이의 ○%만 재료 공식으로 나뉨". 차이가 모두 0이면 "—".
- R3.7 재료별 표(폰에서는 재료 카드). |재료 총차이| ≥ |프로젝트 총차이| × 30% 인 재료는 강조.
- R3.8 설명 문장은 **템플릿**(생성형 AI 아님): "PJ-○ 차이 ±○원(±○%) 중 " + 몫(사용량·고시가·미분해·기타·나누지 않은 단가)을 **절댓값 큰 순 상위 3개**, 각 "이름 ±○원(○%)". %는 몫 ÷ 총차이, 정수 반올림.
- R3.9 미분해 몫 문구: 음수면 "시장가 상승분보다 덜 오름 → 이전 재고 사용(평가 시차) 등 확인", 양수면 "시장가로 설명되는 것보다 더 비싸게 삼 → 구매 조건·환율 확인". 원인을 단정하지 않는다.
- R3.10 분해 합계와 총차이가 1원 이상 다르면 "검산 불일치" + 예외로 보냄(정상 공식이면 생기지 않으므로 코드 오류 감시용).

## R4. 화면 4 · 확인 필요 · 메모 · 확정 · 예외 · 설정
- R4.1 **확인 필요** (설정에서 기준값 변경 가능, 기본값은 시연용)
  - ① |차이율| ≥ 5% **그리고** |차이| ≥ 300,000원
  - ② |차이| ≥ 2,000,000원 (비율 무관)
  - ③ Σ|재료별 미분해 몫| ≥ Σ|재료별 단가 효과| × 50% **그리고** Σ|재료별 미분해 몫| ≥ 300,000원 (지표가 있는 재료만, 재료끼리 상쇄되지 않게 절댓값 합)
  - ④ 견적 기준월 → 생산 완료월 6개월 이상
  - 배지에 사유 번호를 적고, 안내 문구 "확인 필요는 틀렸다는 뜻이 아니라 사람이 볼 차례라는 뜻입니다."
- R4.2 프로젝트마다 원인 메모 + "확정" 체크. 템플릿 문장을 메모에 넣는 버튼. 원인을 자동으로 정하지 않는다.
- R4.3 **예외 목록과 처리 규칙** (버리지 않고 사유와 원본 행을 보여준다)

  | 사유 | 단위 | 그 프로젝트는 |
  |---|---|---|
  | 중복 행 (값이 같음) | 행 | 첫 행만 쓰고 두 번째 행을 예외로. 프로젝트는 정상 계산 |
  | 중복 행 (값이 다름 = 충돌) | 행 | 어느 쪽이 맞는지 추측하지 않음 → **계산 보류** |
  | 견적 없음 / 실적 없음 | 프로젝트 | 목록·합계·기종 집계에서 **제외**, 예외에만 표시 |
  | 견적 없음 / 실적 없음 | 재료 (한쪽에만 있는 재료 행) | **계산 보류** (조용히 버리지 않음) |
  | 단위 불일치 / 빈 값·0 이하 | 재료·프로젝트 | **계산 보류**: 목록 맨 아래에 "계산 보류" 배지로 표시, 금액은 "—", 합계·기종 집계·확인 필요 판단에서 제외 |
  | 검산 불일치 | 프로젝트 | 계산은 표시하되 "검산 불일치" 배지, 합계에서 제외 |

  단위는 자동 변환하지 않는다(g→kg 추측 금지). *(개정: 중간점검 2, 2026-11-13 — 재료 단위 누락·값이 다른 중복을 명시)*
- R4.6 원본 행 검사(위 표)와 확인 필요 계산은 분리한다. **설정(기준값)을 바꾸면 원본 검사는 그대로 두고 확인 필요·기종 주의만 다시 계산**한다.
- R4.4 설정: 운영 담당자 이름(상단 표시), 확인 필요 기준값(5%, 30만, 200만, 50%, 6개월), 기종 주의 기준값(5%, 5%p), 자가 검산 결과(예시 A~G 통과/실패).
- R4.5 메모·확정·설정은 localStorage에 저장. 저장 실패해도 화면은 작동.

## 완료 기준
1. 자가 검산: 정답.md 예시 A~H가 **모두 오차 1원(비율 0.01%p) 미만으로 일치**.
2. 일부러 넣은 오류 5건이 R4.3 처리 규칙대로 예외 목록에 나온다.
3. 가상 데이터에서 기종 6개 모두 "기종 주의"가 "판단 불가"가 아닌 값으로 나온다(데이터가 충분하다는 확인).
4. 360px·1280px에서 화면 1~4를 모두 쓸 수 있고 가로 스크롤이 없다(캡처를 validation/에 남김).
